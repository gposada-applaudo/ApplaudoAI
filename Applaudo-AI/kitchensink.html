Scroll Reveal

.reveal → .is-visible added by IntersectionObserver in script.js · one-time trigger

Add .reveal to any section or container. script.js observes it and adds .is-visible at 12% viewport intersection. The CSS transition animates from the hidden state.

Hidden state (.reveal)
.reveal {
  opacity: 0;
  transform: translateY(20px);
  transition:
    opacity 560ms cubic-bezier(0.22,1,0.36,1),
    transform 560ms cubic-bezier(0.22,1,0.36,1);
}
Visible state (.reveal.is-visible)
.reveal.is-visible {
  opacity: 1;
  transform: none;
}

/* Observer disconnects after firing.
   No re-trigger on scroll-up. */
